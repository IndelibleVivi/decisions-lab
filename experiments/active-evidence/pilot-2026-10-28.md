# E2 首次原生实验：已知有限世界中的取证规划

状态：**COMPLETED（2026-10-28）**。设计与执行同日；操作者选择下列三条件及固定上限后完成真实采集。事前设计和原始记录独立冻结；本报告不改写 10-24 的角色实验或续采其 missing。

## 问题与解释范围

主要问题：给定完整的假设、先验、观察映射、损失表和精确后验，模型选择的多步策略能否降低相对 myopic 的完整任务损失？这是已知有限模型中的 planning fidelity 实验。开放自然语言取证、来源可靠性判断、网页搜索与未知观察模型均不在本轮范围。

同一环境查询预算下，模型与 stop、checklist、myopic、optimal 四种确定性策略比较。synthetic controls 不消耗模型调用；本轮不是等 provider calls 的因果比较。模型若只赢 stop，不能据此声称具备多步取证价值。等调用的 repeated-stop 对照需要独立的采样、聚合和失败契约，留作后续设计。

## 固定设计

- 原创 suite：`decision_lab.evidence.build_suite(seed=20261028)`，沿用 7 families、16 个 world，公开相同假设与损失；seed 只改变呈现顺序，不增加独立样本。
- 每个模型每 world 两次 replicate，共 32 planned episodes。所有正常答案、业务 abstain、API unknown/refusal/error 和 missing 留在分母；不挑最好一次。
- 每轮仅发送 retained manifest 中的 native body 和必要 header；本地 actual world、oracle 和评价不发送。query 的实际观察只在回答应用后进入后续输入。
- 每个 episode 最多 `min(max_queries, len(queries))` 次查询，另一次 terminal 决策。当前题本每 replicate 最多 38 calls；每模型 **76 attempts / questions**，最多 3 dependent rounds。默认每请求一次 attempt，无自动重试。
- 主要终点：left=myopic，right=模型的 `prior_weighted_family_equal.total_loss.delta_right_minus_left`；负值表示模型损失较低。分列 terminal loss 与 query cost，并按 family 显示轨迹。
- 机制判据：XOR 是否完成两问互补；无信息、不可得材料和稳健停止是否浪费查询；旧版／邻实体是否误导；非对称代价下是否过早承诺。
- 默认 controls 的 prior/family 等权总损失：stop 2.342857、checklist 1.828571、myopic 1.400000、optimal 1.257143。myopic→optimal 的全题本改善空间为 1/7，来自 XOR。报告精确有限差距，不做显著性或总体 CI 声明。

## 固定原生条件与停止边界

操作者选定组合：CF `@cf/cloudflare/clef`、`@cf/cloudflare/clef-flash` 作主比较；OpenRouter `baseten/mammoth-1:free` 作有限规划参照。各自独立保留 requested/returned model、endpoint、round 和 attempts，不自动切换路线或付费 fallback。

完整三条件组合最多 **228 attempts / questions、2,000,000 序列化输入 bytes**。本次消费上限：CF 本项目保守核销 **2,500 Neurons**，同时要求本日账户共享用量观察与本地预留后仍保留 **1,000 Neurons** 日免费 margin；OR 只选当前目录零价 free route，最多 76 attempts，不启用付费 fallback。操作者选择仅 Mammoth 时上限相应缩为 76 attempts / questions。序列化 bytes 是调度约束，不是 provider tokenizer 或账单硬上限。

CF 在首次发送前读取当日正式用量；无法取得可信读数或凭据时停止对应条件，不能把旧读数当今天的余量。每次发送前按模型完整 context window 预留，已报告 usage 后才释放差额；未知或 uncertain 保留完整预留。预算、免费 margin、HTTP／native contract 错误或 uncertain 任一触发即停，保留 checkpoint 与 missing。到日边界不自动续跑。

本次核对的官方来源：[Clef](https://developers.cloudflare.com/workers-ai/models/clef/)、[Clef Flash](https://developers.cloudflare.com/workers-ai/models/clef-flash/)、[Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)、[OpenRouter 原生 Decisions 模型目录](https://openrouter.ai/api/v1/models?output_modalities=decisions)。模型页／目录是公开契约与标价证据，不能证明账户可用或此次费用。执行时在本地冻结实际选中条件与核对结果。

三条件在 XOR 的 8 个 episodes 中都问两次后正确 commit。Clef 与 Mammoth 在这份题本上达到多步 oracle 相同的总损失；myopic 的差距来自 XOR。Flash 同样取得 XOR 收益，却在 unavailable 的 4 个 episodes 先买了无效证据再 abstain，多付 1；在 uninformative 的 4 个 episodes 选择损失 2 的 abstain，放弃先验下风险 0.8 的 commit。因此“会追问”与“知道何时停止”必须分别测量。

Clef/Mammoth 各 28 次 commit、4 次业务 abstain，2 次实际 wrong commit；后两次发生在 uninformative 的低先验 world。按给定先验选择最小期望损失不等于每个枚举 world 都答对。Flash 24 次 commit、8 次业务 abstain、0 次 wrong commit，但整体损失反而更高；单看错误 commit 计数会奖励过度暂缓。所有 terminal decisions 仍为 32/32。

返回 label 分别为 `clef`、`clef-flash`、`baseten/mammoth-1-20261021`；label 是本次响应声明，不认证底层权重。原生报告 input tokens 分别为 37,636、39,856、33,888，output tokens 为 0、0、60；零输出 token 是 provider usage 字段，不能推断没有计算。累计 HTTP elapsed 分别约 55.61、53.14、64.74 秒，不含免费路线的本地节流等待，也不是统一端到端产品延迟比较。OR 的 usage.cost 合计 0；CF 未返回逐次费用，保持 null。provider usage、保守 reservation 与实际账单是不同对象，账户用量观察留在本机。
